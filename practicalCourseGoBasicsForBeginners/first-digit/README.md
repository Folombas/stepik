# Поиск первой цифры числа

## Описание
Программа находит первую цифру натурального числа несколькими способами. По условию задачи, число не превышает 10000, но алгоритмы работают для любых неотрицательных целых чисел.

## Условие задачи
Дано неотрицательное целое число. Найдите и выведите первую цифру числа.

**Формат входных данных**
На вход дается натуральное число, не превосходящее 10000.

**Формат выходных данных**
Выведите одно целое число - первую цифру заданного числа.
