# Обработка чисел с плавающей точкой

## 📖 Описание задачи

Программа считывает число типа `float64` и обрабатывает его по следующим правилам:

### Условия обработки:
1. **Если число ≤ 0**:
   - Выводится сообщение: `"число R не подходит"`
   - Где `R` - исходное число с 2 знаками после запятой

2. **Если число > 10000**:
   - Выводится исходное число в **экспоненциальном представлении**
   - Экспонента должна быть в **нижнем регистре** (например, `1.234e+06`)

3. **Если 0 < число ≤ 10000**:
   - Число **возводится в квадрат**
   - Дробная часть **обрезается** до 4 знаков после запятой (без округления)
   - Выводится результат

### Формат ввода/вывода:
- **Ввод**: Одно число типа `float64`
- **Вывод**: Результат обработки согласно условиям выше
- **Важно**: Программа читает из stdin и пишет в stdout без лишних сообщений
