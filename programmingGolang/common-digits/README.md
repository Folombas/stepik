# 🔢 Поиск общих цифр двух чисел

## 📖 Описание задачи

Даны два числа в диапазоне от 0 до 10000. Цифры в каждом числе не повторяются (гарантируется условием). Необходимо найти все цифры, которые присутствуют как в первом, так и во втором числе, и вывести их в том порядке, в котором они встречаются в первом числе.

### Входные данные
- Два целых числа, разделённых пробелом
- Каждое число в диапазоне от 0 до 10000
- Цифры в каждом числе не повторяются

### Выходные данные
- Цифры, которые есть в обоих числах, разделённые пробелом
- Порядок вывода соответствует порядку цифр в первом числе
- Если общих цифр нет, выводится сообщение "Общих цифр не найдено"

### Пример
Вход: 564 8954
Выход: 5 4

text

## 🧠 Алгоритм решения

### Шаг 1: Проверка входных данных
1. Считываем два числа из стандартного ввода
2. Проверяем, что числа находятся в допустимом диапазоне (0-10000)
3. Проверяем условие уникальности цифр в каждом числе

### Шаг 2: Преобразование чисел
1. Преобразуем оба числа в строки для удобства работы с отдельными цифрами
2. Используем `strconv.Itoa()` для конвертации

### Шаг 3: Создание множества цифр второго числа
1. Создаём map (хеш-таблицу) для хранения цифр второго числа
2. Ключи - цифры (символы), значения - булевы флаги
3. Это позволяет выполнять проверку наличия цифры за O(1)

### Шаг 4: Поиск общих цифр
1. Итерируем по цифрам первого числа
2. Для каждой цифры проверяем её наличие в множестве цифр второго числа
3. Если цифра найдена в обоих числах, добавляем её в результат

### Шаг 5: Вывод результата
1. Если найдены общие цифры - выводим их через пробел
2. Если общих цифр нет - выводим соответствующее сообщение

## ⏱️ Сложность алгоритма

- **Временная сложность:** O(n + m), где n и m - количество цифр в числах
- **Пространственная сложность:** O(m) для хранения цифр второго числа

## 🛠️ Структура программы

### Основные функции:

1. **main()** - точка входа, обработка ввода/вывода
2. **hasUniqueDigits(str string) bool** - проверка уникальности цифр
3. **findCommonDigits(str1, str2 string) []string** - поиск общих цифр

### Особенности реализации:

1. **Проверка уникальности:** Используется map для отслеживания уже встреченных цифр
2. **Поиск общих цифр:** Применяется подход с множеством для оптимального поиска
3. **Сохранение порядка:** Результат сохраняет порядок цифр из первого числа
